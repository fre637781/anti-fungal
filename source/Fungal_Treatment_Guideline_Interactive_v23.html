資料來源與方法

  • Only the uploaded documents are used. No web sources or external treatment recommendations were added.
  • Where a guideline gives a genus-level recommendation, the same recommendation is not presented as independent species-level evidence; species cards are labelled accordingly.
  • Priority reflects the source wording (preferred/first-line/alternative/salvage and SoR), not a new ranking invented for this file.
  • A/B/C/D in ECMM-style documents: A strongly supports, B moderately supports, C marginally supports, D recommends against. IDSA 2016 uses Strong/Weak plus evidence quality.
  • FUNDICU 2024 is retained as diagnostic/research context only and is not used to create treatment priorities.

核心文件： （文末 bibliography 可直接點擊 DOI / PubMed） Global guideline for rare mould infections (2021) + supplement; Global guideline for mucormycosis (2019) + supplement; Global guideline for rare yeast infections (2021) + supplement; Global guideline for endemic mycoses (2021) + supplement; Global guideline for cryptococcosis (2024) + supplement; Global guideline for candidiasis (2025) + supplement; IDSA Aspergillosis guideline (2016); ESCMID/ECMM/ERS Aspergillus guideline (2017); ESCMID/ERS chronic pulmonary aspergillosis guideline; Nature Reviews invasive candidiasis review (background evidence only); FUNDICU 2024 (diagnostic/research context only).

重要限制：部分罕見菌只有 case reports / case series，文件本身無法提供可比較的藥物排名；此時頁面明確標示「Evidence-limited」而不自行補齊。Candida 的部分罕見 species 在 2025 文件中主要提供 taxonomy / susceptibility context，而非獨立 species-specific RCT，因此其卡片沿用 genus-level candidaemia recommendation並要求 AFST，而不宣稱存在獨立 species-level evidence。
